Decision 01

Build on my machine, deploy to the cloud only when it counts

Context
The student cloud budget and VM quota could not hold the eight services and the build agents at the same time.
Options
  1. Run Jenkins agents inside the AKS cluster.
  2. Build and deploy everything locally.
  3. Build locally with Kaniko; deploy only stage and master to AKS.
Cost
The cluster has to be switched on before a stage or master build and off after it, by hand. Every build depends on one workstation.
